# INTA Web Dev Class Template

This template will clone all of the class starter code and install the npm https server.

To use it, click "Use this template" and "Open in a new codespace" on the top right.

<img width="653" height="100" alt="Screenshot 2025-09-07 at 5 18 33 PM" src="https://github.com/user-attachments/assets/e903e75c-e54d-4d9e-b174-b913c36c8c58" />

Note: This might take a few minutes. 

When it's done, you should see the following files in your codespaces:

<img width="297" height="410" alt="Screenshot 2025-09-07 at 5 19 22 PM" src="https://github.com/user-attachments/assets/93d1b10d-7f17-49a2-8d06-cc78e8458bbd" />

And you should be able to run the command `http-server` in the terminal.
